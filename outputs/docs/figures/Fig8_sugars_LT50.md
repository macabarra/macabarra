# Figura 8. Azúcares solubles totales frente a LT₅₀

Archivos: `outputs/figures/Fig8_sugars_LT50.tif` y `.png`.
Datos: `outputs/data_txt/Fig8_data.txt`.

## Qué muestra

Panel A: accesiones de *L. luteus* (C102, C195, C226, C98; n = 60 hojas). Panel B:
subconjunto de cuatro especies (*L. albus*, *L. mutabilis*, *P. sativum*, *V. faba*; n = 60).
Puntos pequeños = hojas; marcador grande = media; elipse = 2 DE. Los azúcares se midieron por
planta antes de la helada, de modo que las tres hojas de una planta comparten el valor de X.
La recta es la regresión de mínimos cuadrados de cada panel. El eje Y está invertido: LT₅₀ más negativa (más resistente) aparece arriba.

## Regresiones

- Panel A: y = -0,56x − 0,91; R² = 0,433; P < 0,001; n = 60
- Panel B: y = -0,57x + 4,34; R² = 0,636; P < 0,001; n = 60
- Las 9 entradas juntas (sin figura): y = -0,22x − 2,87; R² = 0,246; P < 0,001; n = 135
